# Building and Testing a Go API with Keploy

A beginner-friendly guide to recording and replaying API test cases with **Keploy** using a Go Echo + PostgreSQL application.

> **What you'll build:** A small Go API workflow where Keploy records real API traffic and turns it into reusable test cases and mocks.

## What you'll learn

- Run a Go API locally
- Connect the application to PostgreSQL
- Send a real API request
- Capture traffic with Keploy
- Generate test cases automatically
- Replay the tests without depending on the original database

---

## 1. Prerequisites

Before starting, make sure you have:

- Go installed
- PostgreSQL running
- Keploy CLI installed
- `curl` installed
